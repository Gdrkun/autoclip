# 波形时间轴与字幕修复

适用于 `feature/speaker-subtitles` 源码分支，更新于 2026-11-03。

## 操作入口

进入成片的“预览与编辑 → 说话人字幕 → 字幕编辑”。音频波形、人物轨道和“当前字幕”编辑区集中显示；完整字幕列表及精确时间可按需展开。

后端新增了波形接口。已在运行的旧开发进程需要重启后端，再刷新前端；上游已发布安装包不包含本分支源码改动。

## 识别不准或多人混在一句

1. 在人物轨道点选字幕，在紧邻的“当前字幕”中修改文字或人物，不需要先展开完整列表。
2. 需要拆句时，把文字光标放在两段台词之间，再点击波形把播放头定位到换人或停顿处，点击“光标处拆句”。
3. 文本光标决定分开哪些文字，播放头决定分开的真实时间；不会按字数比例猜测时间。拆分后每句至少 0.1 秒。
4. 新句默认标为“未知”，请在人物下拉框确认归属。可以随时“试听当前句”。
5. 误拆后可以撤销；同一人物、同一字幕行且位于当前镜头内的相邻句，可通过“合并下一句”重新合并。合并不会越过当前镜头去修改其他区域。

## 漏句与抢话

- **漏句**：在波形上拖选漏掉的音频，点击“选区补句”，填写正文并选择人物，再加入当前草稿。未选区时，“补一句”从当前播放位置开始，初始时长最多 2 秒。
- **两人同时说话**：选中已有句，点击“补重叠字幕”，填写另一人的话并确认人物。默认使用另一字幕行，允许起止时间与原句重叠。
- 当前渲染能力为重叠双行。波形本身不能识别人物或恢复漏掉的台词；可使用下面的局部模型重新识别，也可手工补句。校正文字后的自动时间对齐现已接入，操作方法见 [快速预选与校正文字时间对齐](QUICK_PREVIEW_AND_ALIGNMENT.md)。

## 选区模型重新识别

1. 在波形空白处拖选当前镜头内 0.1–60 秒音频，点击“重新识别选区”。沿用识别设置中选择的本地 Whisper medium 或 SenseVoiceSmall 及提示词。
2. 识别过程只提取选区音频，在独立短任务队列中处理；可取消本次任务，不会停止项目的整片分析或渲染。断开界面后可以在同一草稿恢复任务状态。
3. 完成后对照原字幕，逐条选择候选，可修改文字、原片起止时间、人物和字幕行，并试听选区。人物只在原句归属明确时沿用；局部聚类编号不会当作可靠的全片身份。
4. 可“替换选区内字幕”或“仅补充字幕，保留原句”。存在手工校对时，替换需勾选明确授权；存在跨选区边界的字幕时，须扩大或调整选区后才能替换。
5. 应用会加入当前字幕草稿的撤销历史，保存草稿后才落盘；不会直接写全片字幕 sidecar 或修改其他草稿。识别期间选区字幕被改动、素材变化或候选时间不合法时会阻止应用，避免覆盖最新修改。

局部识别使用仅 ASR 路径，跳过 CAM++ 声纹提取。连续同配置修正复用独立本地 worker，空闲 120 秒释放；模型或提示词变化时重新创建，取消、失败和超时会清理当前 worker。首次调用仍有模型加载开销，识别质量和重叠发言恢复能力取决于原模型。

接口为 `POST /api/v1/studio/{project_id}/subtitle-repairs`、`GET /api/v1/studio/{project_id}/subtitle-repairs/{job_id}` 和 `POST /api/v1/studio/{project_id}/subtitle-repairs/{job_id}/cancel`。创建请求包含 32 位十六进制 `request_id`、原片秒数 `start/end`、`backend`、`prompt` 和从波形取得的 `source_version`。同一编号与请求内容可重试读取原任务，不会重复启动识别。结果起止统一为原片毫秒，OpenAPI 包含请求约束和响应模型。

## 起止时间调整

- 拖动字幕块整体移动；拖动两侧边缘只调整对应起点或终点。拖动中先预览，松手后只提交一次草稿修改，取消拖动不提交。
- 拖动范围限定为当前镜头，时长至少 0.1 秒。横跨镜头边缘的原字幕可先“裁到当前镜头”，再调整边界。
- “显示范围”可选择 10 / 30 / 60 / 120 秒；前后按钮翻动时间窗，“跟随播放头”回到正在校对的位置。
- 标尺默认显示当前镜头的相对时间，可切换为原片时间。“精确时间与微调”中的数字明确使用原片时间；支持 `分:秒.毫秒`，也提供 ±0.1 秒按钮。
- “吸附边界”只对齐附近字幕边缘或播放头，吸附距离最多 0.12 秒，可以关闭；不会强行把停顿认定为一句话的边界。
- 起止框未完成的输入仍可编辑；无效输入不写入字幕正文，继续阻止保存与导出。本机记录会在刷新或重新进入同一草稿后恢复这些时间输入，Esc 可取消。
- 关闭循环试听会让当前句在边界停止；拖动视频进度、切换镜头或跳到别处，会退出原来的循环范围。

## 保存与数据

修改通过当前草稿的原有保存与版本冲突检查落盘。其他草稿、原片和既有成片保留；需要在 MP4 中看到改动时，请保存后重新导出。

普通改字和调整时间不会重新开启已关闭的双色字幕。另一窗口更新识别任务时，本窗口跟随其状态结束轮询，保留当前修改；不会把另一任务的结果自动覆盖到当前稿。

波形来自本地 FFmpeg 实际音轨，只解码当前可见的最多 120 秒区间，返回最多 1600 个峰值；按素材身份和区间缓存，每个项目最多保留 64 个缓存文件。加载失败时，文字校对与数字时间调整仍可使用，不会触发云端识别或模型下载。

## 波形接口合同

`GET /api/v1/studio/{project_id}/subtitle-waveform`

| 参数 | 约束 |
|---|---|
| `start` | 原片秒数，有限数值且不小于 0 |
| `end` | 原片秒数，晚于 start，区间最多 120 秒 |
| `points` | 整数 64–1600，默认 800 |

成功响应为 `{start_ms,end_ms,peaks,source_version}`；起止字段是原片毫秒，`peaks` 为 0–1 的音量峰值数组，`source_version` 是素材身份哈希，不返回文件系统路径。

无效参数返回 422，项目或素材不存在返回 404。该只读接口会生成项目内波形缓存，不修改字幕、草稿或原片。OpenAPI 中包含请求约束与响应模型。

## 验证范围

新增回归覆盖文本与时间分割、同人物合并、独立重叠字幕、拖动预览与单次提交、取消和选区、颜色保持、循环关闭及进度跳转。真实 FFmpeg 验证了峰值、延迟音轨、缓存复用、坏缓存恢复与区间限制；实际 Chrome 验证了完整手工修复、草稿持久化和 390px 布局。

此前手工编辑证据不代表一小时真实素材全链路或双平台安装包验收通过。新增局部识别的隔离回归、准备好的本地模型实测及 Chrome 结果见本次变更留痕；源码验证与安装包验收分别记录。
