# AI 选片偏好

可选的 [画面反应辅助选片](VISUAL_REACTIONS.md) 会将连续全景帧观察到的动作和互动提供给本选片流程，补足字幕中的非语言反应。默认关闭，需要视觉模型与画面分析许可；不要求固定人物框选。

导入前在“你想优先看什么？”选择唱歌、搞笑、网络流行梗、迷因，也可以直接填写“制作要求”。快捷项可以组合和取消，自由文本保持可编辑，最多 1000 字；制作要求和角色名均为空时沿用原选择标准。

例如：

> 优先保留唱歌、搞笑互动、网络流行梗和迷因，减少日常闲聊。唱歌保留自然乐句；搞笑和玩梗保留铺垫、包袱和对方反应。不要编造梗的出处，也不要为了凑时长带入无关内容。

这些偏好通过原 `instruction` 导入字段保存为项目 smart_import/plan 要求。Studio 在自动制作和确认后制作的内容选片路线将它传入 Celery task，再传到同进程流水线：

- 一次通读字幕选片：偏好进入每个窗口的模型提示，选择和分数以兴趣匹配、片段完整性和传播价值为依据，解析重试保持同一偏好。
- 回退分步路线：偏好进入大纲候选、时间定位和 LLM 评分，保持真实字幕时间、ID、输出结构和原质量过滤。类别示例只在用户要求对应内容时适用，尊重排除项。
- 画面选片：自动内容制作路径也传递原文字要求给已有画面分析；不会因为填写偏好自动开启画面发送权限或切换供应商。
- 常规项目重试可以从保存的 smart_import 读取原要求；Studio 显式传递空字符串时清空旧要求，避免重试重新捡回旧偏好。

时间线原始响应缓存按偏好哈希区分，修改偏好不会复用无偏好/其他偏好的旧响应；原文件保留，制作要求和背景均为空时仍使用旧命名。无需数据库迁移，不改全局类别提示词或模型配置。

偏好是给模型的选择标准，并不保证每条素材都存在符合要求的片段。未开启歌声检测时，字幕路线主要依据转写文字，缺少歌词/声音描述或仅出现在画面里的梗可能无法判断；需要人工检查。歌声漏转写和梗识别准确率不在本次代码验证中证明。

开发验证：修复前 HTTP 导入保存的要求未进入内容选片，任务入口不接受偏好；修复后相关模型边界/失败/缓存回归 145 项、Studio 导入 74 项通过，最终偏好定向复验 14 项通过。完整前端门禁 lint/types/300 tests/build 通过，新增表单请求断言定向 5 项通过。Edge 组合四个快捷项并补充自由要求，真实页面生成的 multipart 请求完整包含文字；请求在浏览器本地拦截，没有下载链接、创建用户项目或调用外部模型。测试均使用独立数据和本机模拟，不是所选真实模型的选片效果验收；全量后端既有门禁失败/超时、安装包及双平台验收仍未完成。

## 生成前自动查询角色背景

在导入页“你想优先看什么？”下填写“角色或组合名”，例如：

> 思诺snow、心宜不是心仪（B站/枝江娱乐）

点击“先查背景”可以预览来源；也可以直接生成，程序会在选片前自动查询。多个名称用顿号、逗号或换行分隔，当前每次处理前 3 个名称，整段最多 200 字。平台或所属组合放在括号内，也会参与搜索。制作要求仍用于表达“优先唱歌、搞笑、人物反差”等具体偏好。

查询使用免费的公开 B站账号信息、萌娘百科正文和 Bing 搜索摘要，不需要单独的付费搜索 API。查询请求只包含名称及平台/组合提示，不包含视频或字幕；取得的摘录及来源 URL 会作为背景上下文提供给原有选片模型，不会新增一次模型调用。B站账号按完整名称匹配；取得账号 UID 时，百科必须链接该账号，避免混用相似账号。资料是参考数据，不能代替当前视频证据，也不能保证覆盖所有梗。

来源面板区分账号简介、百科正文和搜索摘要。资料不全、找不到资料、断网或刷新失败会显示对应状态；无可用背景时继续按视频和制作要求选片。已有有效资料在刷新完全失败时保留，并明确标记使用旧资料。修改名称会清除当前预览，防止把旧角色当作新结果。

公开资料缓存 7 天，可点击“重新查询背景”更新。每个项目另外保存 `metadata/character-background.json`，在原有重试和实际任务执行时恢复；按项目绑定上下文，不在并行项目间共享人物背景。时间线缓存同时区分制作要求和背景内容，背景变化后不复用旧响应。不填角色名时不发起查询，旧项目无需迁移。

新增验证：真实开发网页使用上述两个名字得到 4 条来源（两个 B站账号及对应百科），二次查询命中缓存。隔离服务实测另一次取得 3 条、明确保留来源；来源数量随服务可用性变化。后端模型边界、自动查询时序、身份过滤、缓存恢复和项目隔离等相关回归 138 项及原 Studio 导入 74 项通过；前端完整 lint/types/305 tests/build 通过。Edge 验证了来源展示、390px 布局、编辑名称清旧结果、断网提示及真实导入 multipart 字段，生成请求在浏览器本地拦截。未调用付费模型；不据此声称真实选片准确率或安装包验收已通过。全量后端既有失败/超时及双平台安装包验收缺口仍保留。
