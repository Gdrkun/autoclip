# AI 选片偏好

导入前在“你想优先看什么？”选择唱歌、搞笑、网络流行梗、迷因，也可以直接填写“制作要求”。快捷项可以组合和取消，自由文本保持可编辑，最多 1000 字；空要求沿用原选择标准。

例如：

> 优先保留唱歌、搞笑互动、网络流行梗和迷因，减少日常闲聊。唱歌保留自然乐句；搞笑和玩梗保留铺垫、包袱和对方反应。不要编造梗的出处，也不要为了凑时长带入无关内容。

这些偏好通过原 `instruction` 导入字段保存为项目 smart_import/plan 要求。Studio 在自动制作和确认后制作的内容选片路线将它传入 Celery task，再传到同进程流水线：

- 一次通读字幕选片：偏好进入每个窗口的模型提示，选择和分数以兴趣匹配、片段完整性和传播价值为依据，解析重试保持同一偏好。
- 回退分步路线：偏好进入大纲候选、时间定位和 LLM 评分，保持真实字幕时间、ID、输出结构和原质量过滤。类别示例只在用户要求对应内容时适用，尊重排除项。
- 画面选片：自动内容制作路径也传递原文字要求给已有画面分析；不会因为填写偏好自动开启画面发送权限或切换供应商。
- 常规项目重试可以从保存的 smart_import 读取原要求；Studio 显式传递空字符串时清空旧要求，避免重试重新捡回旧偏好。

时间线原始响应缓存按偏好哈希区分，修改偏好不会复用无偏好/其他偏好的旧响应；原文件保留，默认空偏好仍使用旧命名。无需数据库迁移，不改全局类别提示词或模型配置。

偏好是给模型的选择标准，并不保证每条素材都存在符合要求的片段。字幕路线只知道转写文字，缺少歌词/声音描述或仅出现在画面里的梗可能无法判断；需要人工检查。歌声漏转写和梗识别准确率不在本次代码验证中证明。

开发验证：修复前 HTTP 导入保存的要求未进入内容选片，任务入口不接受偏好；修复后相关模型边界/失败/缓存回归 145 项、Studio 导入 74 项通过，最终偏好定向复验 14 项通过。完整前端门禁 lint/types/300 tests/build 通过，新增表单请求断言定向 5 项通过。Edge 组合四个快捷项并补充自由要求，真实页面生成的 multipart 请求完整包含文字；请求在浏览器本地拦截，没有下载链接、创建用户项目或调用外部模型。测试均使用独立数据和本机模拟，不是所选真实模型的选片效果验收；全量后端既有门禁失败/超时、安装包及双平台验收仍未完成。
