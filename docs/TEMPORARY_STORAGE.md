# 临时工作目录

在 **设置 → 应用 → 临时工作目录** 输入运行 AutoClip 的电脑上的绝对路径并保存，例如 `E:\AutoClipCache`。支持中文和空格；AutoClip 在所选目录下创建专用的 `AutoClipTemp` 子文件夹。页面显示实际工作路径和磁盘剩余空间。

- 留空或点击“恢复默认”时，使用当前数据目录下的 `temp` 文件夹。
- 保存前检查路径和写入权限；失败时保留原设置。
- 保存后，新分配的上传暂存文件、音频工作文件、渲染中间文件、封面取帧及 ZIP 发布包使用新目录。已经分配的文件继续使用原路径。
- 不自动移动或删除旧临时文件；原片、项目、断点续跑记录、模型缓存和最终成片的位置保持原样。浏览器“下载”目录由浏览器设置决定。
- 自定义目录所在磁盘须在任务执行时保持可用。磁盘移除或权限改变后，可回到此设置选择其他目录。

配置独立保存在数据目录下的 `temporary-storage.json`，不修改系统 `TEMP` / `TMP`，也不改写 `.env`。API 与 worker 在每次分配工作空间时读取文件；已运行旧版代码的进程首次升级需要重载，之后只修改目录无需重启。

实现覆盖 Starlette 在进入上传接口前的 multipart 磁盘暂存，不仅是上传完成后的文件保存。原子写入项目 JSON / 字幕的文件仍在目标旁创建，避免跨盘替换破坏原子性。不同磁盘间交付无片尾成片或片尾失败时，先复制到目标旁的临时文件，再原子替换最终文件；失败保留原片和已有成片。

源码验证：`backend/tests/test_temp_storage.py` 覆盖配置持久化、另一进程读取、大文件实际落盘、目录切换、无效/不可写路径、保存失败、跨盘交付失败保护、真实 FFmpeg 说话人字幕与 ZIP 输出、分段断点保留。测试使用隔离数据和合成素材，不调用付费模型。
