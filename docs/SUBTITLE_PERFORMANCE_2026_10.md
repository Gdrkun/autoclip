# 字幕校对与处理耗时优化

适用于 `feature/speaker-subtitles` 源码分支，更新于 2026-10-31。现有原片、草稿和输出继续保留。

## 校对字幕

- 桌面上视频和字幕并排，预览保持可见；其他成片设置折叠到下方。窄屏使用上下布局。
- 字幕每页最多显示 60 条；搜索、说话人筛选和待修正筛选继续可用。分页只影响展示，保存仍包含完整草稿。
- 使用“上一句 / 下一句”定位，或在字幕文字框中按 `Alt + ↑ / ↓`；`Ctrl + Enter` 试听当前句。打开“循环试听”可以反复听这一句。
- “批量修改与替换”可选择当前页、指定说话人、统一偏移时间或替换搜索文字。时间偏移只作用于选中字幕，越界时整次拒绝；文字替换作用于选中字幕，未选择时作用于当前切片。其他切片的字幕保持原值。
- 文字替换使用字面量、不区分大小写，替换后的单条字幕须有正文且不超过 2000 字。批量操作和逐句修改支持撤销 / 重做。
- 时间框仍支持秒数和 `分:秒`；离开时间区或按 Enter 应用，Esc 取消。未完成的时间编辑继续阻止保存、导出和另存新版本。
- `Ctrl + S`（macOS 为 `⌘ + S`）保存草稿。本机暂存做短暂防抖，并在离开页面前补写，减少输入时的同步存储开销。

## 配置人物和样式

- 编辑器的转写模型及提示词读取已保存的本地转写配置，可临时调整；不会固定切回 Whisper。
- “人物与样式”提供“标准底部”“大字安全区”预设；字号、横向和纵向位置均可直接输入数字，也可拖动滑块。
- 预览中的虚线框支持鼠标拖拽和方向键微调。播放头不在字幕上时，会用当前切片的一句字幕演示样式，并显示“样式预览”；实际视频与 ASS 仍按真实字幕时间生成。
- “记住此样式 / 应用我的样式”保存和复用本机布局。“记住本项目人物 / 套用项目人物”在同一项目内复用人物名称及颜色，套用时保留每句文字、时间和归属。
- 本机样式和人物预设存放在当前浏览器 / 桌面 WebView 的本地存储，清理浏览器数据会移除预设；不会自动修改其他已保存草稿。套用后仍需保存草稿。
- 保存草稿之后重新导出，已有 MP4 保留为原版本。

## 减少等待

- 新导入默认每个平台先生成 3 条，可在“制作偏好 → 优先生成数量”选择 1 / 3 / 10；其他候选保留为按需生成。显式选择同时覆盖字幕评分路线和无评分的视觉候选。旧项目未指定时沿用原规则。
- 长视频仍按原有 180 秒分段，保留重叠边界、全局人物归属和逐段恢复。一个任务复用一个独立推理进程及已加载模型；全部分段命中缓存时不启动模型进程。
- 已有字幕的纯声纹缓存独立于字幕正文、转写提示词和 ASR 选择；修改这些内容后，复用声纹并重新关联当前字幕。没有字幕时，转写结果仍按素材、模型及提示词校验缓存。
- 连续短区间的多张画面合并为一次 FFmpeg 解码；稀疏采样和尾帧修复继续使用逐帧路径。画面扫描范围、复核预算和许可保持原有规则。
- 字幕任务轮询只读取轻量状态，结束后停止；请求不会重叠，旧任务响应不会覆盖新识别结果。识别期间继续校对产生的新修改会保留，新结果可显式应用。
- 播放进度变化复用字幕预览的排序与行分配结果；草稿 JSON 比较按草稿变化计算，避免每次播放更新遍历整个文档。
- 项目页新增“处理耗时明细”，区分说话人字幕、音轨提取、推理、画面初筛、连续画面复核、AI 选片、取景及渲染等阶段。它是项目累计时间，包含重试；部分阶段互相包含，不能相加当作一次任务的总用时。
- 页面采用路由按需加载，减少打开应用时加载编辑器和设置页的代码。
